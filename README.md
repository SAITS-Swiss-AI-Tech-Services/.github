# .github

Org-level defaults for [SAITS-Swiss-AI-Tech-Services](https://github.com/SAITS-Swiss-AI-Tech-Services).

- `profile/README.md` — the public org profile shown to every visitor of the org page.
- `profile/assets/` — wordmark in light and dark variants.

The member-only profile and the generated repo index live in
[`.github-private`](https://github.com/SAITS-Swiss-AI-Tech-Services/.github-private).

Changes to `profile/README.md` go live as soon as they land on the default branch.
